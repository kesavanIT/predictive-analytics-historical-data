# Predictive Analytics Using Historical Data

## Project Overview

This project uses historical sales data to build a predictive model for forecasting future sales trends.

## Objectives

- Clean and preprocess historical data
- Analyze sales trends
- Build a predictive regression model
- Evaluate model performance
- Forecast future sales
- Visualize predictions

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- GitHub

## Model

Linear Regression was used with time-based and seasonal features.

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Forecast

The model predicts sales for the next 30 days based on historical sales patterns.

## Conclusion

The project demonstrates how historical data can be used for predictive analytics, trend analysis, and data-driven forecasting.
